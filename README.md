     Project Overview
This project focuses on analyzing overall business sales performance using Power BI. The dashboard provides a consolidated view of Sales, Profit, Quantity, Category performance,
Regional contribution, Customer segments, and Monthly trends, enabling data-driven decision-making for business stakeholders.

     Tools & Technologies
Power BI Desktop
Data Modeling & DAX
Interactive Visualizations
Filters & Slicers

     Key Steps Performed
Data Cleaning & Preparation
Data Modeling
Measure Creation (DAX)
Dashboard Design

     Key Insights
Total Sales: ₹1.34M
Total Profit: ₹175.23K
Total Quantity Sold: 22K units

     Outcome
This dashboard provides a 360-degree view of business performance, helping stakeholders:
Track KPIs efficiently
Identify high-profit categories
Understand customer behavior
Make informed strategic decisions
